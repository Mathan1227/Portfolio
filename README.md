## ⚡ Overview

Official engineering portfolio of **Mathan Dinesh**, Full-Stack Developer and AI & Deep Learning Engineer based in Coimbatore, India (B.Tech IT, SREC Class of '26). 

Engineered with a high-performance Noir Cyberpunk aesthetic, bold editorial typography, and a hardware-accelerated 60fps/120fps bidirectional scroll engine.

---

## 🚀 Key Features

* **Studio Rim Light Hero Section:** Clean cutout portrait with ambient breathing glow and snappy one-time letter arrival on "MATHAN DINESH".
* **Bidirectional Scroll Engine:** Direction-aware focal trigger system that reliably animates elements both when scrolling **DOWN** and scrolling **UP**.
* **Curtain Split Reveal Shutter:** High-tech cyberpunk split curtain on Section 2 that unlatches left & right with a glowing central laser slice.
* **3D Perspective Tunnel Cards:** Project cards glide in with staggered 3D depth, gyroscopic mouse tilt tracking, and spotlight flashlight illumination.
* **Interactive Live Widgets:**
  * Real-time 60fps radar sweep simulation on the YOLOv8 vision card.
  * Transit pulse dot simulation on the Bus Booking portal.
  * Audio equalizer spectrum visualizer on the Bio-Sonic acoustic grid.
* **Cascading Technical Arsenal:** Magnetic hover physics on tech chips with zero DOM reflow overhead, accompanied by live liquid fluency meter fills.
* **Interactive Engineering Process:** Vertical circuit line draw-down with physical laser collision collision step illumination.
* **Gravitational Singularity Finale:** Section 5 Black Hole accretion core, SVG fractal noise chromatic liquid distortion, and one-click contact matrix.

## 🛠️ Built With

* **Markup & Structure:** HTML5 (Semantic, Accessible)
* **Styling & Layout:** [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism & Cyberpunk Noir Themes
* **Typography:** [Google Fonts](https://fonts.google.com/) — *Anton*, *Syne*, *Outfit*, *Plus Jakarta Sans*, *JetBrains Mono*, *Caveat*
* **Iconography:** [Lucide Icons](https://lucide.dev/)
* **Engine:** Pure Native JavaScript (ES6+) with `requestAnimationFrame` and `IntersectionObserver`

## 💻 Local Development

Clone the repository and serve with any static web server:

```bash
# Clone the repository
git clone https://github.com/<your-username>/portfolio.git

# Navigate into the project directory
cd portfolio

# Run with Python built-in server
python -m http.server 3000

# Or run with Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.

## 🌐 1-Click Deployment

### Deploy to Vercel (Recommended)
```bash
npx vercel
```

### Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Set the source branch to `main` and root `/`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
